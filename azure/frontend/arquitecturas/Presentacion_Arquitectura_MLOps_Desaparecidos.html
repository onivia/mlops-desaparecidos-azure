Las 7 validaciones del PR ▾

Las pruebas del workflow ci-pr.yaml verifican la consistencia del frontend y del contrato esperado hacia la API. De forma simple, cubren:

  • Que el HTML cargue y contenga la estructura base esperada.
  • Que exista la constante API_BASE apuntando al backend en Azure.
  • Que el frontend invoque /api/predecir con método POST.
  • Que el frontend invoque /api/entrenar con método POST.
  • Que el frontend invoque /api/entrenar/{run_id} con método GET.
  • Que existan estructuras base de payload/ejemplo necesarias para el consumo de la API.
  • Que los módulos clave del frontend para predicción y entrenamiento estén presentes.

El caso FAILED se demostró introduciendo deliberadamente un error en el endpoint HTML, y luego se mostró el caso SUCCESS tras corregirlo.
